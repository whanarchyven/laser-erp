# laser-erp

Стенд и код агента для интеграции лазерного станка (CypCut / LXDS) с ERP.

Пошаговый тест на реальном станке: **[docs/ТЕСТ-НА-СТАНКЕ.md](docs/ТЕСТ-НА-СТАНКЕ.md)**

Подключение сети и установка сервера для сисадмина: **[docs/ТЗ-СИСАДМИНУ.md](docs/ТЗ-СИСАДМИНУ.md)**

## Сервер одной командой

Нужны Docker и Node.js. В папке проекта:

```bat
Запустить-сервер.cmd
```

На Linux и macOS: `bash server/start.sh`.

Скрипт поднимает Convex, его панель и веб, сам задаёт ключи и в конце печатает адрес веба, `BaseUrl` агента, ключ агента и ключ внешнего API. Первый запуск скачивает образы и собирает веб. Настройки сохраняются в `server/.env`, данные — в томе Docker.

Другое приложение ходит на тот же адрес, что агент (`http://<сервер>:3211`), с заголовком `Authorization: Bearer <API_TOKEN>`. Методы, тела и ответы: **[docs/API.md](docs/API.md)**.

Полный контекст чата, решения и план продолжения: **[docs/CHAT_HANDOFF.md](docs/CHAT_HANDOFF.md)**
